CASE STUDY / DEPLOYED

Janus: AI-powered task automation

A conversational agent that connects an n8n workflow to memory and task tools.

Project repository ↗

Problem

Janus explores how a conversational agent can use connected tools when a request calls for search, calculation, or code execution.

Users

People interacting with the hosted Janus chat interface.

Data / inputs

The workflow receives chat messages, uses conversational memory for context, and can call Google Search through SerpApi, a calculator, and a code-execution tool.

Approach and architecture

An n8n Chat Trigger passes messages to an AI Agent connected to Simple Memory and the listed tools; the workflow uses OpenAI to produce conversational responses.

What I built (my role)

I built the conversational task automation agent with n8n and OpenAI, integrated memory, and connected Google Search, Calculator, and code-execution tools.

Result

The agent is deployed with a hosted chat demo.
